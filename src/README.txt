Optimal PDF Reader
=================

A small Windows PDF reader with no ads, no sign-in, and no extra panels.

How to use
----------
1. Run OptimalPdfReader.exe.
2. Click Open and choose a PDF, or drag a PDF into the window.
3. Use Zoom - / Zoom + for quick zooming.
4. Click Snapshot, drag over the area you want, then save it as a PNG image.
5. Use the PDF toolbar inside the viewer for page navigation, search, rotate, and thumbnails.

Notes
-----
- This app keeps files local.
- It uses Microsoft Edge WebView2 only to render PDFs.
- If Windows says WebView2 is missing, install/update Microsoft Edge.
